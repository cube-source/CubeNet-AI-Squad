# Code of Conduct: CubeNet AI Squad

## 1. The Goal
The CubeNet AI Squad project is a technical endeavor aimed at pushing the boundaries of AI integration within the Source Engine. To achieve this, we require an environment focused on technical excellence, mutual respect, and constructive collaboration.

Our primary objective is to build a sophisticated AI ecosystem. This requires a community that values logic, precision, and the shared goal of improving the project.

## 2. Expected Behavior
We expect all contributors, whether submitting code or reporting bugs, to adhere to the following standards:

- **Technical Respect:** Critique the code, not the person. Provide actionable, specific feedback during code reviews.
- **Collaborative Spirit:** Help others get up to speed. If you see a newcomer struggling with the build process or the API, offer guidance.
- **Transparency:** Be honest about the limitations of your contributions and open about potential bugs or regressions.
- **Professionalism:** Maintain a professional tone in issues and pull requests. Keep discussions focused on the technical merits of the proposal.

## 3. Unacceptable Behavior
To maintain a productive development environment, the following will not be tolerated:

- **Toxicity:** Personal attacks, harassment, or derogatory language directed at any community member.
- **Disruption:** Intentional derailment of technical discussions or spamming issues with non-constructive content.
- **Bad Faith Contributions:** Submitting intentionally broken code or misleading documentation to hinder project progress.
- **Hostility:** Aggressive responses to constructive criticism or refusal to engage in the established project workflow.

## 4. Enforcement
The maintainers of CubeNet AI Squad reserve the right to take the following actions based on the severity of the violation:

1. **Warning:** A formal request to correct behavior, typically delivered via a private message or issue comment.
2. **Temporary Restriction:** Temporary removal of commit access or a timeout from community discussions.
3. **Permanent Ban:** Permanent removal from the project and blocking of all further contributions.

## 5. Reporting
If you encounter behavior that violates this code, please report it directly to the project maintainer via private message or the designated security/contact email. All reports will be handled with discretion and reviewed on a case-by-case basis.

---
*By contributing to CubeNet AI Squad, you agree to abide by these standards to ensure the project remains a professional and productive space for all.*
