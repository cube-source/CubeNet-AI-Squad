# Contributing to CubeNet AI Squad

We welcome contributions from the SourceMod community. Whether you are a SourcePawn expert or a TF2 tester, your help is valued.

## 🛠️ Development Workflow

1. **Fork the Repository**: Create your own copy of the project.
2. **Create a Feature Branch**: .
3. **Implement Changes**: Follow the coding standards established in .
4. **Test Locally**: Ensure your changes do not introduce regressions in bot identity persistence or AFK transition logic.
5. **Submit a Pull Request**: Provide a clear description of the changes and any issues they resolve.

## 📜 Coding Standards

- **Documentation**: All new functions must include a brief header explaining their purpose.
- **Consistency**: Maintain the established naming conventions (e.g.,  prefixes).
- **Stability**: Avoid monolithic function blocks; decouple logic into smaller, testable helpers.

## 🤝 Communication

For major architectural changes, please open an issue first to discuss the implementation strategy with the maintainers.
